# 全国空气质量可视化分析大屏

本项目是“项目一：环境与人类发展大数据”的可视化作品。系统使用固定周期 `2026-04-01` 至 `2026-04-07` 的全国城市空气质量数据，围绕 AQI、PM2.5、PM10、SO2、NO2、O3、CO 等指标，完成数据采集、清洗聚合、后端接口、前端大屏展示和 PPT 汇报材料。

## 一、项目简介

作品主题：全国空气质量可视化分析大屏

主讲人：杨文天

核心目标：

- 展示全国重点城市 AQI 空间分布。
- 找出周期内 AQI 较高城市和空气质量较好城市。
- 分析全国 AQI 的 7 日变化趋势，并用简单线性回归做 3 日趋势预测。
- 展示污染物结构、AQI 等级分布和重点城市逐日热力变化。
- 形成可运行网页、汇报 PPT、代码压缩包三类交付物。

## 二、技术栈

- 前端：React、TypeScript、Vite、Tailwind CSS
- 可视化：ECharts
- 后端：Flask、Flask-CORS
- 数据处理：requests、pandas
- 汇报材料：PowerPoint PPTX

## 五、主要目录和模块用途

### 1. 后端数据处理模块

```text
api/air_quality.py
```

用途：

- 下载每日全国城市空气质量 CSV。
- 使用 pandas 把按小时记录聚合成按城市、按日期的平均值。
- 根据 AQI 数值划分等级：优、良、轻度污染、中度污染、重度污染、严重污染。
- 判断每个城市的主要污染物。
- 计算全国平均 AQI 趋势。
- 用简单线性回归生成未来 3 天 AQI 趋势预测。
- 汇总生成前端大屏需要的 JSON 数据结构。

答辩可以这样讲：

> 这个模块是整个项目的数据加工核心。原始 CSV 是按日期、小时和污染物类型组织的，不能直接画图，所以我先用 pandas 清洗和聚合，再生成地图、排行、趋势、热力图等图表需要的结构化数据。

### 2. 后端接口模块

```text
api/app.py
```

用途：

- 创建 Flask 应用。
- 提供 `/api/dashboard` 接口，返回完整大屏数据。
- 提供 `/api/map`、`/api/city-rank`、`/api/trend`、`/api/pollutants`、`/api/heatmap`、`/api/levels` 等接口。
- 在生产构建后，负责提供 React 静态页面。

答辩可以这样讲：

> 这个模块负责把数据处理结果提供给前端。前端不直接读 CSV，而是请求 Flask API，这样数据处理和页面展示分开，结构更清晰。

### 3. 数据生成脚本

```text
api/generate_air_quality_data.py
```

用途：

- 调用 `air_quality.py` 中的数据处理函数。
- 下载或读取缓存 CSV。
- 生成 `air_quality_dashboard.json`。

答辩可以这样讲：

> 如果老师问数据怎么来的，可以说我写了单独的数据生成脚本，运行后会自动下载 7 天 CSV 并聚合成大屏数据。为了答辩稳定，我使用固定周期数据，保证每次运行结果一致。

### 4. 前端首页模块

```text
src/pages/Home.tsx
```

用途：

- 请求 `/api/dashboard` 获取大屏数据。
- 组织页面标题、核心指标卡片、6 个可视化图表和底部结论。
- 控制单页大屏布局，保证 16:9 首屏展示完整。

答辩可以这样讲：

> 这个文件是前端主页面，负责把后端返回的数据分发给各个图表组件。页面上方是总体指标，中间是可视化图表，底部是自动生成的三句分析结论。

### 5. 前端数据类型定义

```text
src/types/airQuality.ts
```

用途：

- 定义后端返回数据的 TypeScript 类型。
- 让前端开发时能检查字段是否正确。

答辩可以这样讲：

> 我用 TypeScript 定义了数据接口，避免前后端字段不一致，比如地图数据、排行数据、趋势数据都有明确结构。

### 6. 全国地图组件

```text
src/components/AirQualityMap.tsx
```

用途：

- 使用 ECharts 地图和散点图展示城市 AQI 分布。

- 鼠标悬停可以查看城市 AQI、等级和主污染物。

答辩可以这样讲：

> 地图用来回答“污染主要集中在哪里”。它比表格更直观，可以快速看出西北、华北等地区的空气质量差异。

### 7. AQI 城市排行组件

答辩可以这样讲：

### 8. AQI 趋势与预测组件

### 9. 污染物玫瑰图组件

答辩可以这样讲：

> 这个图用来回答“污染物构成是什么”。由于不同污染物单位和数值范围不同，CO 做了展示缩放，并在图表说明中标注。

### 10. 重点城市热力图组件


答辩可以这样讲：

> 热力图用来观察重点城市是否只是某一天高，还是连续多天偏高。它能补充排行图看不到的时间变化。

## 六、前端 6 个图表的分析逻辑

1. 全国城市 AQI 空间分布图：看空气质量的地理分布。
2. AQI 城市排行图：找出周期内 AQI 较高城市。
3. 全国 AQI 趋势与预测图：观察 7 日趋势，并展示 3 日预测。
4. 污染物玫瑰图：分析主要污染物结构。
5. 重点城市日期热力图：观察重点城市逐日变化。
6. AQI 等级分布图：统计全国城市日样本的等级结构。

## 七、答辩时可以讲的三句核心结论

1. 本周期全国平均 AQI 为 `55.7`，整体以“优”和“良”为主。
2. 和田地区是本周期 AQI 均值最高城市，平均 AQI 为 `146.3`，需要重点关注颗粒物与臭氧叠加影响。
3. 甘孜藏族自治州空气质量表现最好，平均 AQI 为 `22.3`，整体处于较低污染水平。

## 九、答辩推荐讲解顺序

1. 先讲选题：空气质量属于环境与人类发展主题，和日常健康、城市治理有关。
2. 再讲数据：使用公开历史 CSV，固定 7 天周期，保证结果可复现。
3. 再讲处理：requests 下载，pandas 清洗聚合，Flask 提供 API。
4. 再讲可视化：React + ECharts 做地图、排行、趋势、热力图、污染物结构和等级分布。
5. 再讲算法：用简单线性回归做 AQI 趋势预测，作为算法嵌入。
6. 最后讲结论：指出重点关注城市、空气较好城市和整体趋势。
