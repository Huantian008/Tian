# 接雨水 2.0 (Trapping Rain Water II) 3D 可视化 — 设计文档

## 概述

实现接雨水 II 算法的 3D 交互式可视化。用户可以看到一个高度图，观察水如何被困在"山谷"中，算法逐步执行的每一步都清晰可见。单 HTML 文件，通过 CDN 加载 Three.js。

## 算法

**接雨水 II**（LeetCode 407）：给定 m×n 的非负整数高度图，计算降雨后能接多少水。水可以向四个方向（上下左右）流动，最终从边界流出。

### 算法流程（最小堆 / 优先队列）

1. 将所有边界格子 `(0, j)`, `(m-1, j)`, `(i, 0)`, `(i, n-1)` 的高度插入最小堆，标记为已访问
2. 维护全局水位线 `waterLevel`（当前弹出格子的高度）
3. 每次弹出堆中最小高度的格子，检查其四个方向的邻居：
   - 若邻居已访问 → 跳过
   - 若邻居高度 < 当前水位线 → 该格子可积水：`waterLevel - height[neighbor]`
   - 标记邻居为已访问，以 `max(height[neighbor], currentHeight)` 入堆
4. 重复直到堆空

### 数据结构

- Min-heap (Priority Queue)：JavaScript 数组实现二叉堆
- visited[m][n]：布尔矩阵标记已访问
- heightMap[m][n]：高度值矩阵
- water[m][n]：积水深度矩阵
- stepHistory[]：步骤历史栈，支持撤销

## 视觉设计

### 3D 场景 (Three.js)

| 元素 | 实现 | 颜色 |
|------|------|------|
| **高度柱** | `BoxGeometry` 立方体，高度 = 格子高度 * 缩放比 | 渐变色：低(绿) → 中(黄) → 高(红)，HSL 映射 |
| **积水层** | 半透明 `BoxGeometry`，叠加在高度柱上方，高度 = 积水量 * 缩放比 | 半透明蓝色 `rgba(64, 160, 255, 0.6)` |
| **当前处理格** | 金色发光边框 / 浮动圆环 | `#FFD700` |
| **已访问标记** | 柱子顶部叠加半透明白色方块 | `rgba(255, 255, 255, 0.25)` |
| **地面** | `PlaneGeometry` 带网格纹理 | 浅灰 `#E8E8E8`，网格线 `#CCCCCC` |
| **场景光照** | 环境光 + 方向光 + 可选点光源跟踪当前格 | — |

### 颜色映射

高度值通过 HSL 色相映射：
- `h = 120 - (height / maxHeight) * 120`（120°=绿，0°=红）
- 饱和度 70%，亮度 55%

### 相机

- **初始视角**：俯视 45° 角，略偏右上
- **OrbitControls**：鼠标左键旋转、滚轮缩放、右键平移
- **初始距离**：根据网格大小自适应

## 交互控制

### 播放控制栏

- **⏮ 重置**：回到初始状态，清除所有访问标记和水
- **◀◀ 后退**：撤销上一步
- **▶ 播放**：自动逐步执行，每步间隔由速度滑块控制
- **⏸ 暂停**：暂停自动播放
- **⏭ 前进**：手动执行一步
- **▶▶ 快进**：跳到最终结果

### 参数控制

- **速度滑块**：范围 50ms–1000ms/步，默认 200ms
- **网格大小选择器**：4×4, 6×6, 8×8, 10×10, 12×12
- **🔄 随机生成**：生成指定大小的随机高度图（值范围 0–9）

### 信息面板

实时显示：
- 当前总积水量
- 堆中剩余格子数
- 已访问格子数
- 当前水位线

### 点击格子

点击 3D 柱子 → 在信息面板显示该格子的：
- 坐标 (row, col)
- 高度
- 积水量
- 是否已访问

## 技术栈

- **Three.js**：CDN 加载（importmap 或 script tag，版本 r160+）
- **OrbitControls**：Three.js 官方扩展，CDN 同源
- **无其他依赖**：纯原生 JS + CSS + HTML
- **模块化**：ES modules（import map 方式）

## 代码结构

单文件 `trapping-rain-water-ii.html`，内部组织：

1. **HTML**：Canvas 容器 + 控制面板 + 信息栏
2. **CSS**：内联 `<style>`，深色主题，flexbox 布局
3. **JS**：
   - `class MinHeap` — 二叉堆实现
   - `class RainWaterEngine` — 算法逻辑 + 步骤历史
   - `class Scene3D` — Three.js 场景管理
   - `class UIController` — 事件绑定 + DOM 更新
   - `main()` — 初始化 + 连接各模块

## 错误与边界情况

- 网格 ≤ 2×2 时不可能积水（无内部格子），提示用户
- 随机生成时确保最大高度合理（当前范围 0–9）
- Three.js 加载失败时显示错误提示
- 步骤历史为空时禁用后退按钮
