# 考研二叉树遍历可视化工具 — 设计文档

日期:2026-07-31
状态:已确认

## 目标

帮助用户(考研 408 数据结构备考者)通过交互式动画理解二叉树遍历:
先序、中序、后序的递归与非递归实现,以及层次遍历。动画展示每一步的
访问顺序、辅助栈/队列的变化,与课本(王道教材)手算过程一一对应。

## 形式与部署

- 单文件原生 HTML + CSS + JavaScript,零依赖、零构建。
- 双击在浏览器打开即可使用,离线可用,便于分享。
- 放置于仓库根目录 `binary_tree_traversal.html`。

## 页面布局

```
┌────────────────────────────────────────────────┐
│  标题:二叉树遍历可视化(考研数据结构)               │
├─────────────────────────┬──────────────────────┤
│                         │  模式选择(7 种)        │
│    SVG 画布              │  树来源(预设×3+随机)   │
│    (树形图,节点圆形)      │  控制条                │
│                         │  遍历结果序列           │
│                         │  辅助结构面板           │
└─────────────────────────┴──────────────────────┘
```

### 7 种遍历模式

| 模式 | 说明 |
|------|------|
| 递归先序 | 根→左→右,展示递归调用栈 |
| 递归中序 | 左→根→右,展示递归调用栈 |
| 递归后序 | 左→右→根,展示递归调用栈 |
| 非递归先序 | 栈模拟,出栈即访问,右子先入栈、左子后入栈 |
| 非递归中序 | 栈模拟,指针沿左子树深入入栈,出栈访问后转向右子树 |
| 非递归后序 | 栈模拟,栈元素带标志位(二次入栈标记 1 才出栈访问) |
| 层次遍历 | 队列,出队访问,左子入队、右子入队 |

切换模式立即重算步骤并回到开头。

## 动画机制

### 预计算步骤序列

选择模式后,用真实算法跑一遍,产生步骤数组。每步事件对象:

```
{ type: 'push'|'pop'|'visit'|'enter'|'exit'|'enqueue'|'dequeue',
  node, aux: 当时的栈/队列快照 }
```

播放器按时间轴推进步骤数组,每步重绘节点颜色与辅助结构面板。
支持:播放 / 暂停 / 单步前进 / 单步后退 / 重置 / 速度滑块。
回退 = 按步骤重放,状态永远一致。

### 颜色语义(统一约定)

- 🔵 蓝 = 当前指针 / 当前递归层
- 🟢 绿 = 入栈 / 入队
- 🔴 红 = 出栈 / 出队
- 🟠 橙 = 正式访问(输出到结果序列)

### 辅助结构面板

- 递归模式:调用栈帧,如 `Pre(B) ← Pre(A)`,展示进入/返回流程
- 非递归模式:辅助栈实时内容,栈顶高亮
- 层次模式:队列实时内容,队首高亮

## 数据结构与树布局

- 树节点:`{ val, left, right }`(JS 对象)
- 布局:满二叉树下标法自动布局,水平位置按层展开,节点不重叠
- 随机生成约束:高度 ≤ 5,节点数 8~15,避免画面拥挤
- 预设树刻意选用考研经典题(王道例题等)

## 验证与测试

1. **手算对照**:预设树期望结果写死为断言(如王道例题树
   A/B/C/D/E/F/G:先序 `A B D E C F G`、中序 `D B E A F C G`、
   后序 `D E B F G C A`、层次 `A B C D E F G`),页面加载时
   console 自动校验。
2. **交叉验证**:非递归与递归实现各自独立编写,运行时对比输出
   序列,不一致标红警告。
3. **边界情况**:空树、单节点树、左斜树、右斜树;随机生成按概率
   混入退化情形。
4. **手动验收**:7 种模式播放/暂停/单步、换树换模式不报错、
   离线双击可用。

## 非目标

- 不做由遍历序列还原二叉树(用户明确未选,可作后续扩展)
- 不做线索二叉树
- 不做移动端适配(桌面浏览器为主)
